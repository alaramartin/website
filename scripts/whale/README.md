# Footer whale art

The swimming humpback in the footer (`app/components/Whale.tsx`) is drawn from
`app/data/whaleInk.json`, which is generated by the scripts here.

```sh
npm run whale:build     # regenerate app/data/whaleInk.json
npm run whale:preview   # same, plus scripts/whale/preview/preview.svg (and .png on macOS)
```

The preview shows several swim-cycle frames, a throat and fin close-up, the real footer
sizes, and dark mode. It uses the same layering as the component. The preview folder is
git-ignored.

## Files

- `build-whale-ink.mjs` is the generator. Everything about the look lives in its **ART**
  section.
- `cruise-mesh.json` is the 2D swim-cycle mesh (30 keyframes, 550 vertices, 1100
  triangles). It was extracted from the whale kit's `svg/cruise-loop-dots.svg`.
- `extract-mesh.mjs` rebuilds `cruise-mesh.json` from that SVG, if the kit ever changes.

## How the drawing works

All art is in rest-frame mesh coordinates: 904 × 338, head on the right, y pointing down.

- **Body:** a smooth closed curve through a ring of outline vertices (`RING`). The
  component re-smooths it every frame as the mesh swims.
- **Throat:** `strands` (pale ribbons), `throatBase` (grey underlay) and `prefin` (strokes
  behind the far fin) are fixed shapes clipped to the live body outline.
  - `TOP` / `BOT` set the band the strands run between.
  - The strand loop controls count, waviness, widths, gaps and taper.
- **Near fin:** `fin` (pale fill) plus `finInk` (pen outline and tip hatching). They follow
  an affine fit of the fin's mesh vertices.
  - `FIN_LINE` controls outline weight.
  - `FIN_HATCH` controls the tip lines.
- **Far fin:** `farFin`, a fixed dark blade.
- **Fluke:** `fluke`, drawn in a local frame from the tail stock (0) to the body outline's
  tail tip (1).

Randomness comes from seeded RNGs (`rng(11)` for the throat, `rng(5)` for the fin
hatching), so output is the same every run.

To try a different variation, change a seed. Adding or removing random calls inside the
strand loops reshuffles every strand after that point.

Colors live in `app/ui/globals.css` (`--whale-ink`, `--whale-paper`, `--whale-pleat`).
`PREVIEW_COLORS` at the top of the generator only affects the preview, so keep them in
sync.
